# SnapMark

Screenshot and PDF plan-markup tool for Mac and Windows: capture, redline, dimension
in feet-inches-sixteenths, measure, compare revisions with overlays, and redact.

This page only holds the downloads. SnapMark is in beta - thanks for trying it.

## Download

Go to **[the latest release](https://github.com/jstelte/snapmark-releases/releases/latest)**
and, under **Assets**, download:

- **Windows:** `SnapMark-Setup-<version>.exe`
- **Mac:** `SnapMark.dmg`

## Installing on Windows

1. Run the setup file.
2. If Windows says **"Windows protected your PC"**, click **More info**, then **Run anyway**.
   This appears because SnapMark is new and not yet code-signed.
3. Follow the steps. No administrator password is needed.

## Installing on a Mac

1. Open `SnapMark.dmg` and drag **SnapMark** into **Applications**.
2. Open SnapMark. If macOS says it can't check the app for malicious software, open
   **System Settings > Privacy & Security**, scroll down, and click **Open Anyway**.
3. The first screenshot asks for **Screen Recording** permission. Turn SnapMark on in
   **Privacy & Security > Screen & System Audio Recording**, then quit and reopen it.
   You may need to do this again after installing an update.

## Help and feedback

- Press **F1** in SnapMark for how-to pages.
- Use **Send feedback...** at the bottom of the main window - it goes straight to the developer.
- SnapMark tells you when a new version is out.
